# football
On this page is a collection of football related data files and presentations.

On here are the outputs from simulations; I write for the Economics Observatory where the forecasts are housed and written about - see e.g. [here](https://www.economicsobservatory.com/scorecasting-the-premier-league-what-prospects-for-the-2026-27-season).

The most recent League Two projections to the end of the season are [here](https://github.com/jjreade/football/l2-end-of-2026-probs-2026-09-10.csv).

Sources for data:
- The Boston United results from the 1930s are (almost certainly) from [www.bufc.drfox.org.uk](https://www.bufc.drfox.org.uk/). But the website appears down, unfortunately, at the time of trying.
- Barnet's come from the brilliant [www.downhillsecondhalf.co.uk](https://www.downhillsecondhalf.co.uk/Football/Records.aspx), a genuinely superb archive which includes a lot of away fan attendance numbers.
- Wealdstone's come from [www.wfchistory.com](https://www.wfchistory.com/first-team-results-archive/).
